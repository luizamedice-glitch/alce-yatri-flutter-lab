# Motorista — Android nativo Kotlin

Diretório reservado para um aplicativo Android Gradle **nativo**, com interface Jetpack Compose. Não executar Flutter neste diretório.

Planejado: estados online/offline, oferta de corrida, aceite, chegada, início e término, localização, notificações, tratamento de conectividade e permissões.

O código do projeto Android ainda precisa ser gerado e compilado. Ver `docs/android-driver-architecture.md`.
